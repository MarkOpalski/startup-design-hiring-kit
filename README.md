# Startup Design Hiring Kit

**A practical guide to hiring designers for early-stage startups.**

This open-source playbook is designed to help founders, product leaders, and early-stage teams make thoughtful, strategic, and bias-aware design hires—especially when hiring their very first or first few designers.

It includes actionable frameworks, role definitions, interview guides, and templates to reduce guesswork and improve hiring outcomes.

**Created by Mark Opalski**

---

## 🚀 Quick Start

1. Clone or fork this repo
2. Read the [playbook](./playbook.md)
3. Explore the `/roles`, `/interview`, and `/templates` folders
4. Customize the templates for your startup
5. Share feedback or contribute via pull requests
